# Management System - Web Frontend

## Description

The Management System Web Frontend is responsible for providing a user-friendly interface to interact with the API Gateway. It allows users to perform various operations such as authentication, data retrieval, and management.

## Software and Requirements

**Requirements:** Node.js v24.16.0 or higher, any browser

**Tools/libraries:** Angular, TypeScript, Vitest, Tailwind

## Set up the project

- Build:

    ```bash
    ng build
    ```

- Start the server:

    ```bash
    ng serve
    ```

- Test via preferred browser: http://localhost:4200
